## 最近在关注什么

最近主要关注 **强化学习（Reinforcement Learning）、Agent Memory 和 Agent Harness**。目前做过一些论文复现，也运行过智能体相关的 benchmark、开发过 OpenClaw 插件，还在一边读论文、一边动手尝试的阶段。

**强化学习 · 从交互和反馈中学习决策**

强化学习是我持续关注的一条主线。在六子棋博弈项目中，我们结合了强化学习、自博弈和蒙特卡洛树搜索（MCTS）。从对局中的决策，到智能体在其他环境里的行动，我感兴趣的是如何利用交互和反馈学习策略，以及当前的选择会怎样影响后续结果。

**Agent Memory · 智能体如何积累和使用经验**

一次对话结束之后，哪些信息值得留下？过去的经历应该如何组织，又怎样在后续任务中被找到和使用？我对智能体记忆的兴趣，围绕这些问题展开：从上下文中的信息，到跨任务保留的经验，理解记忆如何参与智能体的工作，以及它与任务表现之间的关系。

**Agent Harness · 智能体如何在环境中完成任务**

模型之外，工具、上下文和执行流程共同构成了智能体工作的环境。我也关注这一层：模型怎样使用工具，与环境交互，并将多个步骤连接成一次完整的任务执行。开发 OpenClaw 插件，是我在这方面做过的一项实践。

评测是探索这些问题的一部分。我测过 **WildClawBench、ClawBench、PinchBench、SWE 和 LiveClawBench**，也希望把论文中的方法、实际运行的过程和评测结果联系起来理解。这里会慢慢记录复现与实验中的尝试、问题和想法。

## 论文复现：Sonata

我做过 [Sonata 的复现实践](https://github.com/Wch727/sonata-reproduction)，关注模型在回答问题前，能否判断自己是否需要更长的思考过程。

这项方法利用模型的隐藏状态预测自一致性，再据此决定直接回答还是进入思考模式。我的复现围绕 **Qwen3-8B** 展开，仓库中整理了校准数据构建、自一致性样本采集、轻量适配器训练和评测流程，也记录了实现与论文设定之间的差异。采样支持中断后继续运行，方便保留和接续实验。

目前公开仓库主要记录实现与实验流程，完整的对照结果还没有整理出来。
