## 最近在关注什么

最近主要关注 **强化学习（Reinforcement Learning）、Agent Memory 和 Agent Harness**。目前做过一些论文复现，也运行过智能体相关的 benchmark、开发过 OpenClaw 插件，还在一边读论文、一边动手尝试的阶段。

**强化学习 · 从交互和反馈中学习决策**

强化学习是我持续关注的一条主线。在六子棋博弈项目中，我们结合了强化学习、自博弈和蒙特卡洛树搜索（MCTS）。我也在 Kaggriculture 农场经营任务中尝试过模仿学习与策略评测。

我想继续了解的方向包括：

- **LLM 与智能体的学习**：数学、代码和多步推理训练，工具选择与行动学习，以及长程任务里的延迟奖励、任务拆解和信用分配。
- **博弈与多智能体**：自博弈、策略学习和搜索，也关注多个智能体之间的协作、竞争与策略互动。
- **从轨迹到持续学习**：离线学习、模仿学习和在线学习，以及训练出来的策略在新任务、新对手面前的泛化与稳定性。
- **反馈与计算开销**：奖励怎样对应真正的任务完成，思考长度和 Token 预算又该如何与效果取得平衡。

这些是我希望深入的问题；已有的实践主要是比赛项目、论文复现和相关实验。

**Agent Memory · 智能体如何积累和使用经验**

我关注长期记忆、经验复用，以及记忆的检索、更新与遗忘。一次交互之后，哪些信息值得留下？已有经验怎样在下一次任务中被找到，又什么时候应该修正或删除？除了记忆的组织方式，我也关心它对实际任务表现的影响，希望通过评测来理解记忆什么时候有帮助、什么时候会引入干扰。

**Agent Harness · 智能体如何在环境中完成任务**

模型之外的上下文管理，也是我正在关注的部分。我开发过 OpenClaw 插件，主要做的是**压缩上下文、提高 Token 使用效率**：在减少上下文占用的同时，保留后续工作需要的信息。这也连接到 Agent Harness 的执行过程——如何让智能体在持续交互中使用有限的上下文，而不是不断堆积历史。

评测是探索这些问题的一部分。我测过 **WildClawBench、ClawBench、PinchBench、SWE 和 LiveClawBench**，也希望把论文中的方法、实际运行的过程和评测结果联系起来理解。这里会慢慢记录复现与实验中的尝试、问题和想法。

## 论文复现：Sonata

我做过 [Sonata 的复现实践](https://github.com/Wch727/sonata-reproduction)，关注模型在回答问题前，能否判断自己是否需要更长的思考过程。

这项方法利用模型的隐藏状态预测自一致性，再据此决定直接回答还是进入思考模式。我的复现围绕 **Qwen3-8B** 展开，仓库中整理了校准数据构建、自一致性样本采集、轻量适配器训练和评测流程，也记录了实现与论文设定之间的差异。采样支持中断后继续运行，方便保留和接续实验。

目前公开仓库主要记录实现与实验流程，完整的对照结果还没有整理出来。
