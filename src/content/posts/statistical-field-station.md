这是我整理的一套数学建模学习资料。目前有 **17 个章节（含数模工具箱）**，另有目录路线图和统计术语表。从描述统计和统计推断开始，逐步延伸到预测、优化、综合评价、微分方程与图论仿真。

[打开在线教程](https://wch727.github.io/statistical-field-station/) · [查看源码](https://github.com/Wch727/statistical-field-station)

## 从问题找到方法

我希望它能方便平时学习，也能在遇到建模题时快速查阅。目录按常见问题组织入口：哪些因素有关、两组数据是否存在差异、怎样预测趋势、如何安排最优方案、系统如何随时间变化。

每章结合公式说明、Python 示例、交互图形和建模应用。阅读时可以先弄清变量和假设，再调整参数观察结果，最后考虑怎样验证模型、解释结论。

## 页面里的内容

交互图形用 D3.js 实现，公式用 KaTeX 渲染。例如，可以调整逻辑回归的系数观察概率曲线，拖动数据点比较相关系数，旋转 PCA 数据观察主成分，或改变 SIR 参数查看传播过程。

正文同时说明适用条件与容易误读的地方：相关不等于因果，交叉验证要防止数据泄漏，综合评价中的权重和指标方向需要解释，模型拟合得好也需要进一步验证。术语表可用于查找概念，再返回章节阅读上下文。

## 怎么阅读

可以从数模工具箱、描述统计、可视化开始，再进入相关分析、假设检验和方差分析。遇到具体建模任务时，也可以直接从目录的决策路线跳转。

例如，预测问题可以先看时间序列与预测专论；综合评价问题则对应熵权法、TOPSIS、AHP 等章节。方法的适用前提和数据条件仍需要结合题目判断。

## 在线与离线使用

页面内的交互计算在浏览器中完成，KaTeX、D3.js 和字体随仓库提供。下载仓库后直接打开 `stats_tutorial.html` 即可离线阅读，无需后端。章节中的 Python 示例需要在另外的 Python 环境中运行，并准备相应依赖与输入数据。

## 实现与验证

章节正文和交互脚本统一维护在构建目录中，再生成独立 HTML 页面。术语数据也从同一份 JSON 生成离线版本，避免两份内容不同步。

最近对全部章节、术语定义和交互计算做了一轮审阅，修正了概率尾部计算、PCA 特征分解、ROC/AUC 同分处理、GM 参数估计、AHP 和 SIR 数值演示等问题，也补充了相应的回归检查。

目前验证包括 **72 项 SciPy 对照测试、23 项桌面与手机页面检查**，以及各章专项数值回归、公式渲染、链接、资源和构建一致性检查。GitHub Actions 在检查通过后发布在线教程。
