这是面向数学建模学习的交互式统计教程。仓库有 **18 个独立 HTML 页面**，包括目录页和 17 个章节，将公式推导、交互图形、工具选择和竞赛问题放在一起。

## 从问题找到方法

目录不只列章节，也按建模中常见的问题提供阅读入口：哪些因素有关、两组数据是否存在差异、怎样预测趋势、如何选择最优方案、系统如何随时间变化。

章节覆盖描述统计、可视化、相关分析、假设检验、方差分析、回归、分类、聚类、模型评估、时间序列、优化决策、综合评价、微分方程、图论与仿真。

## 页面里的内容

每章结合 KaTeX 公式、D3.js 图形和可调整的实验参数。既可以阅读推导，也可以观察参数变化如何影响结果，再对照建模工具箱与竞赛场景。

内容整理时关注模型的用途、输入输出、假设、变量含义、可信度和局限。代码示例与图形之外，也有数据泄漏、模型验证和论文表达等提醒。

## 怎么阅读

可以从数模工具箱、描述统计、可视化开始，再进入相关分析、假设检验和方差分析。遇到具体建模任务时，也可以直接从目录的决策路线跳转。

例如，预测问题可以先看时间序列与预测专论；综合评价问题则对应熵权法、TOPSIS、AHP 等章节。方法的适用前提和数据条件仍需要结合题目判断。

## 在线与离线使用

所有计算在浏览器中完成，KaTeX、D3.js 和字体随仓库提供。下载后可直接打开 stats_tutorial.html，不需要启动后端；也可以使用 GitHub Pages 的在线版本。

[打开在线教程](https://wch727.github.io/statistical-field-station/) · [查看源码](https://github.com/Wch727/statistical-field-station)

## 实现与验证

页面相互独立，由目录和章节链接连接。仓库的开发检查包括统计计算、内部链接、本地资源完整性和浏览器冒烟测试。

```bash
npm ci
npm test
npm run test:all
```
