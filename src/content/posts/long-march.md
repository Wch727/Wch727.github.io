这是为大创申报准备的长征主题作品。项目将路线导览、历史阅读、知识库问答和剧情答题放进一个多页面平台，使用 Streamlit、Python 与 Chroma 实现。

## 沿着路线阅读

从首页进入长征路线后，可以按篇章选择节点，再进入独立展项。展项包含图文讲解、人物专题、语音导览和互动入口，路线为阅读提供了顺序。

读完展项后，可以进入闭卷闯关。作答前只给出任务线索，提交后再展示答案解析、历史小课堂和下一节点推荐，让阅读与答题各有自己的过程。

## 知识库与内容生成

知识库页面提供基于仓库资料的 RAG 问答，也有知识卡片和错题复盘。平台另有讲解稿与短视频脚本生成入口，可以围绕已有内容组织不同形式的讲解。

模型通过统一的 provider 适配层接入。配置和可用模型由平台策略决定；未提供 API Key 时，会回退到本地知识导览，图文展项仍能浏览。

## 活动与展示

除了个人阅读，平台还包含活动模板、分享链接、二维码、排行榜、个人战绩和数据大屏。管理员后台用于维护活动、题库、知识库和模型开放设置。

语音讲解使用 edge-tts 生成缓存音频。数字讲解员由形象、语音、字幕与轻量动效组合，适合现有的 Streamlit 页面。

## 本地运行与部署

当前主入口是 app.py，云端主运行路径由 Streamlit 直接调用核心逻辑，不需要另行启动 FastAPI。仓库保留了 FastAPI 代码，供本地开发和后续扩展。

部署到 Streamlit Community Cloud 时，主文件选择 app.py。首页与主要互动组件的 HTML、样式和轻量脚本分别放在 templates、assets/styles 和 assets/scripts 中，Python 页面负责数据与跳转逻辑。
