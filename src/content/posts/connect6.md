这是我和队友参加首届北京市大学生“人工智能+”创新大赛时做的六子棋项目。比赛在 **2025 年 12 月**，当时我们以“请输入文本”为队名参赛，获得六子棋项目**季军（一等奖）**。现在把训练、对弈、评测和复盘的代码整理进了这个仓库。

## 从棋盘规则到策略学习

六子棋使用 19×19 棋盘，黑方首回合下一子，此后双方每回合各下两子，横、竖或斜向连成至少六子即获胜，没有禁手。一个回合要考虑两个落点的配合，也要兼顾对手下一轮的威胁。

项目采用 AlphaZero 风格的策略价值网络与 MCTS：网络给出落点倾向和局面价值，搜索进一步比较候选行动，再用自对弈产生训练数据。除了自对弈训练，也保留了数据生成、监督预训练和实验训练入口，便于分别尝试不同的数据来源与训练流程。

## 训练与评测

训练部分包括经验回放、优化、检查点保存与恢复，支持 CPU 和 CUDA。小规模运行可以减少自对弈局数与搜索次数，先确认整条流程能跑通，再增加训练规模。

模型评测支持指定双方权重、交换先后手，保存逐局棋谱并统计胜负和与得分率。评测默认包含规则辅助，也可以同时关闭双方的辅助来比较模型与搜索本身。比较结果时，需要把搜索次数、规则辅助和先后手设置一起记录。

```sh
python -X utf8 evaluate.py --model checkpoints/model_a.pt --opponent-model checkpoints/model_b.pt --games 20 --simulations 400 --output logs/match.json
```

## 两个网页入口

| 入口 | 用途 |
| --- | --- |
| 项目 AI | 使用无需权重的启发式对弈，或加载本项目训练的模型 |
| Katagomo | 调用外部引擎，查看推荐落点，导入导出 SGF / JSON 棋谱并逐步复盘 |

Katagomo 页面需要另外下载官方六子棋引擎与模型。它使用的是外部引擎，和本项目训练的模型分开使用、分开比较。项目还保留了桌面 GUI，以及比赛版、混合版等历史入口。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `game/` | 棋盘规则、启发式、引擎连接与棋谱读写 |
| `model/`、`mcts/` | 策略价值网络、串行与批量搜索 |
| `training/` | 自对弈、回放、优化和检查点 |
| `web/` | 两个网页界面的静态资源 |
| `docs/`、`tests/` | 使用说明与回归检查 |

权重、开局库、原始数据和运行结果没有随源码分发。使用已有模型时需要确认权重确实加载成功；命令行对弈在模型路径不存在时会随机初始化网络。

这个项目让我把强化学习、自博弈与搜索放进同一个具体问题中，也留下了继续做训练、对比与复盘的工具。
