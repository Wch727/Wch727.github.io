ICPC / CCPC · 与 CODEX 共创

算法模板库

196 份代码模板190 个 C++ 测试入口A4 双栏手册

围绕 ICPC / CCPC 的训练与比赛需求，这份模板库将算法实现、使用说明、验证代码和纸质手册放在同一套维护流程中。它是我与 Codex 共创的项目，也会随着训练继续完善。

从查找到调用

内容覆盖基础技巧、数据结构、字符串、图论、数学、动态规划、搜索、计算几何与实现调试。中文说明记录适用条件、复杂度、易错边界和关键公式；模板索引、接口说明、变量与调用约定帮助查找和使用具体模块，另有 STL 速查表与赛事建模结论。

让实现可以检验

根据当前 README，仓库包含 190 个 C++ 测试入口，直接引用模板本体，结合边界样例、独立对照与随机对拍进行验证。使用时仍需针对题目设置容量、模数、下标和初始化参数，并检查对应边界。

从代码到纸质手册

配套的 LaTeX 手册采用 A4 双栏排版，共用算法源码与说明，保留完整实现，并支持按需要选择打印内容和字号。部分实现有第三方来源与许可说明，具体见对应文件注释。
